| Tipo                          | Descripción                                                 | Ejemplo                                                                          |
| ----------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **Datos sucios**              | Son datos con errores de formato, escritura o codificación. | Edad escrita como “veinte” en lugar de `20`, o fecha “32/15/2024”.               |
| **Datos nulos**               | Campos vacíos o sin valor.                                  | `Cabin = NULL`, `Age = NULL`.                                                    |
| **Datos anómalos (outliers)** | Valores que se alejan mucho del comportamiento general.     | Un pasajero con edad `250` años o tarifa `10000` cuando el resto ronda `50–200`. |
|                               |                                                             |                                                                                  |
