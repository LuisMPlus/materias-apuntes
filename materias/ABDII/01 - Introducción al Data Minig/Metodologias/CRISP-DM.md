# CRISP-DM (CRoss-Industry Standard Process for Data Mining)
![](../../../../Adjuntos/Pasted%20image%2020260912131724.png)
Actualmente es la **metodología estándar y abierta más utilizada** para guiar proyectos de minería de datos, análisis avanzado y ciencia de datos
de proyectos de Minería de Datos.
Consta de 6 etapas o fases, las cuales van iterando y adaptándose al resultado final que es en sí la toma de decisiones:

1. **Comprensión del negocio**: Se definen los objetivos del proyecto y los criterios de éxito desde la perspectiva de la empresa.
2. **Comprensión de los datos**: Se recopila la información inicial y se explora para detectar problemas de calidad o relaciones preliminares.
3. **Preparación de los datos**: Se limpian, seleccionan y transforman las variables para construir el conjunto de datos definitivo.
4. **Modelado**: Se seleccionan y aplican diversas técnicas de modelado o algoritmos de aprendizaje automático.
5. **Evaluación**: Se verifica la calidad del modelo y se comprueba si realmente responde a las necesidades del negocio.
6. **Despliegue**: Se implementa el resultado en un entorno operativo o de producción para generar valor continuo.
