# ¿En que se basa este análisis?
En estadística exploratoria se utilizan **gráficos y métodos** que permiten analizar la distribución de los datos e identificar características relevantes, tales como:
- **Valores atípicos (outliers)**
    
- **Saltos o discontinuidades** en la serie
    
- **Concentraciones de valores** en determinados rangos
    
- **Forma de la distribución** (simetría, sesgo, dispersión)
    
Este análisis puede realizarse:
- **Sobre todos los casos en conjunto**, para obtener una visión global.
    
- **Separando por grupos**, donde los gráficos y estadísticos ayudan a determinar si los datos provienen de una sola población o de varias, considerando la variable que define los grupos como factor diferenciador.

Además, mediante técnicas [[Graficas]] y **contrastes no paramétricos**, es posible comprobar si los datos provienen de una población con distribución aproximadamente normal.
Entre las estadísticas y representaciones más utilizadas se destacan:
- **Intervalos de confianza**
    
- **Media**
    
- **Gráfico de tallo y hojas**
    
- **Diagrama de caja y bigotes (boxplot)**
    
- Otros métodos complementarios de visualización y resumen.
