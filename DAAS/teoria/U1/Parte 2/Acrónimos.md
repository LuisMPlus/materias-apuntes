# Acrónimos - Unidad 1 (Parte 2)

| Siglas | Nombre Completo | Significado / Contexto |
| :--- | :--- | :--- |
| **MOF** | Meta-Object Facility | Meta-metalenguaje estándar del OMG (nivel M3) para definir metamodelos. |
| **EMOF** | Essential MOF | Subconjunto minimalista de MOF para metamodelos sencillos. |
| **CMOF** | Complete MOF | Extensión completa de MOF para metamodelos complejos (como UML 2.x). |
| **QVT** | Query / View / Transformation | Estándar del OMG para transformaciones de modelos basados en MOF. |
| **OCL** | Object Constraint Language | Lenguaje de restricciones formales de consulta y sin efectos laterales (OMG). |
| **EMP** | Eclipse Modeling Project | Proyecto general de Eclipse para herramientas y frameworks de MDD. |
| **EMF** | Eclipse Modeling Framework | Framework de Eclipse para generación de código a partir de modelos Ecore. |
| **GMF** | Graphical Modeling Framework | Framework de Eclipse para generar editores gráficos basados en EMF + GEF. |
| **GEF** | Graphical Editing Framework | Framework para manipulación gráfica e interactiva en Eclipse. |
| **TMF** | Textual Modeling Framework | Subproyecto de Eclipse para sintaxis textuales y gramáticas de DSLs. |
| **JET** | Java Emitter Templates | Motor de plantillas de Eclipse para generación de código (M2T). |
| **ATL** | ATLAS Transformation Language | Lenguaje DSL de transformación de modelos desarrollado por INRIA. |
